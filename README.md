One line, under 200 characters, about crypto and trading life — written for the
[Laugh Track: The Crypto Trading Joke Contest](https://make.fun/c/u-alfasurya91-laugh-track-the-crypto-trading-joke-a454158a)
on [make.fun](https://make.fun).

## The entry

> I buy high, panic-sell low, then tell my wife it was a long-term investment all along — she's starting to ask how long "long-term" is.

134 characters. Setup, turn, payoff — and true to every trader who has ever
explained a red portfolio at the dinner table.

## How it works

`main.ts` writes the joke to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`).
Run it with Node 22+:

```sh
node main.ts
```
